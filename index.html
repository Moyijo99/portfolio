Projects

Streaming

Real-Time Event Tracking Pipeline

A production-style streaming pipeline: a Python/Faker producer publishes synthetic user events to Kafka; a consumer ingests them into PostgreSQL with no data loss under burst load. An Airflow DAG orchestrates hourly ELT into ClickHouse, and dbt staging/mart models power dashboard-ready datasets in Metabase. Containerised as 7 services with Docker Compose for one-command local deployment.

Abuja Weather Intelligence Pipeline

A batch ingestion pipeline pulling real weather data from the Open-Meteo API into BigQuery, with schema validation via Great Expectations to catch drift before it reaches downstream models. dbt staging and mart layers apply consistent data contracts on top, orchestrated with daily Airflow runs on Astronomer.
